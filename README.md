# Веб-приложение ButerBrod
Программное средство предназначено для ознакомления с информацией о товарах, заказа различных вариаций бутербродов, а также осуществления покупки из предложенного ассортимента продукции и просмотра калорийности выбранного товара.

Проект разработан в среде программирования Visual Studio Code c использованием языков программирования JavaScript, PHP. Для создания пользовательского интерфейса и веб-страниц в программном средстве также были использованы языки гипертекстовой разметки HTML и стилей CSS. БД разработана с использованием СУБД DBeaver.
